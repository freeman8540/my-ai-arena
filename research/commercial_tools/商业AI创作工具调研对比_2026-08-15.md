### 1.2 最值得先试的组合

1. **中文小说草稿**：Kimi / DeepSeek / 豆包起草 + 蛙蛙写作或 Novelcrafter 管大纲；要本地正典和伏笔，再接开源 `show-me-the-story` / InkOS。
2. **英文长篇**：Sudowrite 或 Novelcrafter 写正文，Scrivener / Campfire 管资料卡，Grammarly / Wordtune 做句级润色。
3. **专业剧本**：Arc Studio 或 Final Draft 出格式化剧本，Filmustage / StudioBinder 做拆解和通告，Boords / LTX Studio 出分镜。
4. **小说视觉化小样**：LTX Studio 或 Katalist 出分镜 → Kling / Hailuo / Runway / Sora 出 5–10 秒镜头 → 剪映或 Descript 合成。
5. **无 GPU 解说视频**：InVideo / Pictory / 剪映；开源对照物是 MoneyPrinterTurbo。
6. **企业口播/培训**：Synthesia 或 HeyGen + ElevenLabs / Azure Speech；不要用免费克隆声音直接上广告。

## 2. 必须先分开的五层

商业目录和 83 项开源库存容易被混成“都能生成视频/小说”。实际应分成五层：

1. **通用模型**：ChatGPT、Claude、Gemini、DeepSeek、Kimi。什么都能写一点，但不负责章节账本、分镜资产和成片。
2. **故事/剧本工作台**：蛙蛙写作、Novelcrafter、Final Draft、LTX Studio。负责结构、格式、协作，不一定自带视频模型。
3. **镜头生成服务**：Sora、Runway、Kling、Hailuo、Vidu。只产出数秒到数十秒镜头。
4. **剪辑与数字人**：剪映、Descript、HeyGen、InVideo。把文案、镜头、字幕、配音编成可发布视频。
5. **语音/配乐/图像配件**：ElevenLabs、Suno、Midjourney。给上面四层补声音和视觉，不替代故事系统。

因此：

- 买了 Sora/Kling，并不等于拥有 InkOS 或 Toonflow 那种小说→资产→成片流水线。
- 开源 `Wan2.2` 能本地出镜头，也不等于商业剪映/Descript 的发布工作流。
- “商业工具”只说明产品形态是付费/SaaS/桌面许可，**不等于输出内容自动可商用**。

## 3. 通用模型与写作助手（30）

这一层解决起草、改写、检索和脑暴，不解决“写成一本可维护的书”。

| 细分 | 代表工具 | 更适合 | 不适合当成 |
|---|---|---|---|
| 国际通用对话 | ChatGPT、Claude、Gemini、Grok、Microsoft Copilot、Poe、Le Chat | 大纲、场景草稿、改写、资料整理 | 长期正典和版本治理 |
| 中文通用对话 | DeepSeek、Kimi、豆包、通义千问、文心、智谱清言、讯飞星火、腾讯元宝、MiniMax | 中文长文、检索、办公和国内模型入口 | 专业剧本格式或成片 |
| 故事向模型产品 | NovelAI、Sudowrite、Dreamily、Character.AI | 续写、角色扮演、二次元/互动叙事 | 出版级审稿和合同文本 |
| 营销文案 | Jasper、Copy.ai、Writesonic、Rytr、Anyword、HyperWrite | 广告、邮件、SEO、品牌语气 | 长篇人物弧和伏笔 |
| 句级润色 | Grammarly、QuillBot、Wordtune | 语法、改写、总结 | 世界观和分集结构 |

**选型要点**

- 只要中文长上下文：Kimi、DeepSeek、Claude、Gemini 通常比营销文案工具更合适。
- 只要“像作家一样续写”：Sudowrite / NovelAI / Dreamily 比 Jasper 更贴小说。
- 这些产品多数可当开源小说 Agent 的上游模型；不要把它们登记进 83 项 GitHub 库存。

## 4. 小说、剧本与故事工作台（28）

这一层才接近 83 项里的 InkOS、show-me-the-story、Final Draft 替代品。

### 4.1 中文写作与长文

| 工具 | 核心能力 | 和开源库存的关系 |
|---|---|---|
| 蛙蛙写作 | 小说、剧本、漫剧和 Agent 全链路 | 最接近“商业版综合创作台”，但仍是云端产品 |
| 秘塔写作猫 / 火山写作 | 纠错、润色、改写 | 对应开源项目里的去 AI 味/审稿辅助，不是长篇引擎 |
| 百度橙篇 / 讯飞智文 / 笔灵 AI | 长文、报告、资料生成 | 更偏知识内容和公文，不是网文连载账本 |

### 4.2 英文/国际小说工作台

| 工具 | 核心能力 | 说明 |
|---|---|---|
| Novelcrafter | Codex、章节、多模型接入 | 最接近开源 OpenFic / StoryForge 的商业形态 |
| Plottr / Campfire Writing / Plot Factory | 时间线、角色卡、世界观 | 规划强、生成弱 |
| Scrivener / Storyist / Squibler | 长篇组织、卡片、导出 | Scrivener 几乎无原生大模型，常和 Claude/ChatGPT 搭配 |
| Milanote | 灵感板和结构墙 | 适合前期，不是写作引擎 |

### 4.3 专业剧本与前期制作

| 工具 | 核心能力 | 说明 |
|---|---|---|
| Final Draft / Fade In / Highland 2 | 工业格式、修订、Fountain | 好莱坞/影视工业默认层 |
| Arc Studio / WriterDuet | 云协作剧本 | 比桌面软件更适合远程编剧组 |
| Celtx / StudioBinder / Dramatify / Filmustage | 拆解、通告、预算、排期 | 进入制片，而不只是“写台词” |
| Boords / StoryboardHero / Katalist / LTX Studio / FinalBit | 脚本转分镜、预演、coverage | 连接下一层视频模型 |

**选择建议**

- 要行业格式：Final Draft 或 Fade In，不要用 ChatGPT 直接“假装是剧本软件”。
- 要中文小说+漫剧一条龙：先看蛙蛙写作；要可审计、可自托管，回到开源 InkOS / Toonflow / ArcReel。
- 要分镜而不是成片：LTX Studio、Boords；成片仍要 Kling/Sora/剪映。

## 8. 商用、数据和地区风险

本目录 138 项全部是商业产品/服务，但风险并不相同。

1. **输出权利 ≠ 产品付费**。免费层、试用点数、带水印导出、团队套餐的商用范围经常不同。
2. **声音克隆和数字人**默认高风险。需要肖像/声音授权，且部分地区有深度伪造限制。
3. **用户内容是否用于训练**因产品和计划而异。长篇小说、未发表剧本不要默认上传到免费聊天产品。
4. **地区可用性**。Sora、Google Flow、部分 Adobe/Google 功能在不同市场并不对称。
5. **中文内容安全策略**会直接挡住某些题材，这不是模型能力问题。
6. **模板、字体、库存素材、BGM** 有自己的许可，和“AI 生成”不是一回事。
7. **API 输出**往往另签企业协议；网页里能下载，不代表 API 结果可进广告。
8. **商业 SaaS 不能登记进 83 项开源库存**。Kling、Sora、剪映、蛙蛙写作都不是 GitHub 开源项目。

## 10. 落地方案

### 方案 A：最低门槛中文小说（纯商业）

```text
Kimi / DeepSeek / 豆包
  → 蛙蛙写作 或 Novelcrafter 管大纲和章节
  → Grammarly / 秘塔写作猫 做句级润色
  → TXT / DOCX 成稿
```

若需要正典、伏笔账本和本地数据，把第二步换成开源 `show-me-the-story` 或 InkOS。

### 方案 B：小说到可继续剪的短剧小样

```text
小说章节
  → 蛙蛙写作 / FinalBit / Claude 出分集剧本
  → LTX Studio 或 Boords 出分镜
  → Kling / Hailuo / Runway / Sora 出镜头
  → ElevenLabs 或 讯飞智作 配音
  → 剪映 / Descript 合成
```

开源对照：Toonflow / ArcReel 负责中间资产和审核，镜头仍可调用上述商业模型。

### 方案 C：专业编剧组

```text
Arc Studio 或 Final Draft
  → Filmustage / StudioBinder 拆解和通告
  → Boords / StoryboardHero 分镜审阅
  → 视频模型只用于预演，不成片
```

### 方案 D：无 GPU 解说视频

```text
主题
  → InVideo / Pictory / Fliki / 剪映
  → 库存素材 + TTS + 字幕
  → 社媒成片
```

开源对照：MoneyPrinterTurbo。两者都不是角色一致的剧情生成。

## 11. 评估时应实际验证的指标

1. **地区和登录**：目标市场能不能直接用，要不要邀请码或手机号。
2. **免费层能否导出无水印、能否商用**。
3. **长篇连续性**：20 章后人物和设定是否只能靠用户自己粘贴上下文。
4. **镜头可用率**：20 个生成结果里有多少能直接进时间线。
5. **角色一致性**：跨镜头的脸、服装、道具。
6. **单位成本**：每千字、每秒视频、每条配音的真实花费。
7. **数据去向**：是否用于训练、能否关闭、能否数据驻留。
8. **导出是否可后期**：分轨、SRT、工程文件，还是只有一个 MP4。
9. **声音/肖像授权**是否覆盖发布平台。
10. **和 83 项开源工具能否衔接**：API、BYOK、工程文件，而不是把两边清单合并。
