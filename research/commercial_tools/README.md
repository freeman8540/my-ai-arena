# 商业 AI 创作工具（独立目录）

> **快照日期：2026-08-15** · **目录规模：138 项**

本目录承接商业产品、闭源 SaaS、商业桌面软件、云 API 与订阅型创作服务的独立清单，覆盖通用写作、小说/剧本、视频、图像设计、语音与音乐。它与仓库原有的 **83 项 GitHub 开源项目库存完全分层**：商业工具没有追加到原有 CSV，也没有改写原有 GitHub 调研报告。

## 文件

- [138 项商业工具明细 CSV](./商业工具明细_2026-08-15.csv)：脚本生成的可筛选数据文件，使用 UTF-8 BOM，便于 Excel/WPS 打开。
- [源数据 JSON](./商业工具目录源数据_2026-08-15.json)：生成输入，保留每项的官方产品页、分类和能力摘要。
- [生成脚本](./generate_commercial_tools_csv.py)：检查 138 项、重复项、必填字段和与 83 项 GitHub 库存的名称/URL 隔离后再写出 CSV。

## 重新生成

在仓库根目录运行：

```bash
python research/commercial_tools/generate_commercial_tools_csv.py
```

脚本会读取本目录的源数据，并将原有 `research/GitHub_AI_小说_剧本_视频生成项目明细_2026-08-13.csv` **仅作为隔离校验输入**。脚本要求该文件仍有 83 行；若商业工具与原清单发生名称或 URL 重叠会直接失败，绝不会静默合并。

- 使用前应按具体产品当前服务条款和相关模型/素材许可复核，尤其是免费层、声音克隆、品牌素材和 API 输出。
