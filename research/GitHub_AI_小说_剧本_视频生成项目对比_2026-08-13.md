### 1.2 最值得先试的组合

1. **中文小说写作**：低门槛选 `show-me-the-story`；超长连载选 `webnovel-writer` / `ainovel-cli`；综合 Agent IDE 选 `InkOS` / `Goink` / `Siming` / `OpenFic` / `Denova`；开放世界看 `OneDay` / `Covel` / `openovel`。
2. **小说改编成短剧**：`Toonflow-app`；若更重视审核、费用和剪映后期，换 `ArcReel`。
3. **动漫/漫剧**：`AIComicBuilder`；若在阿里云模型生态内，优先 `LumenX`。
4. **解说型短视频**：`MoneyPrinterTurbo`，无需部署本地视频扩散模型。
5. **完全掌控基础模型**：先试 `Wan2.2 TI2V-5B`；显存更紧可评估 `MAGI-1 4.5B FP8` 或 CogVideoX 的量化/offload 路线。
6. **研发型完整链路**：文本层选 `InkOS` / `novel-studio`，分镜层选 `PenShot`，视频模型选 `Wan2.2`；用 FFmpeg/Remotion 做最终合成。

## 2. 必须区分的四层

很多项目都叫“视频生成”，实际不是同一类产品：

1. **小说生成器**：解决世界观、人物、长程记忆、逐章生成与修订。
2. **剧本/分镜工具**：把创意或小说转成场次、对白、镜头和视频 Prompt。
3. **视频生产工作台**：编排 LLM、生图、视频 API、TTS、字幕和 FFmpeg，输出整条成片。
4. **视频基础模型**：只负责从文字/图片/音频生成数秒到数十秒镜头，通常不负责剧情、配音和剪辑。

因此，基础模型 Stars 高不代表可以“一句话生成完整短剧”；生产工作台能出完整视频，也不代表它自带可本地运行的视频模型。

### 工作台横向判断

- **旁白解说/知识视频**：MoneyPrinterTurbo 最直接；它用库存素材换取低成本和稳定画面。

- **Agent 自动制片**：ViMax 或 OpenMontage；前者更聚焦叙事视频，后者覆盖研究、素材和后期的工具更多。

## 8. 落地方案建议

### 方案 A：最低门槛中文小说

```text
show-me-the-story
  + DeepSeek/OpenAI 兼容 API（省本机算力）
  或 Ollama/LM Studio（数据本地）
  → TXT/Markdown 成书
```

适合个人作者。先用 10–20 章小项目测试人物一致性、伏笔回收和每章成本，再扩展长篇。

### 方案 B：小说到可继续剪辑的短剧

```text
小说
  → Toonflow 或 ArcReel（改编、角色、分镜、资产）
  → 外部图像/视频模型 API，或自建 Wan2.2 服务
  → TTS + FFmpeg
  → 剪映草稿（ArcReel）/ 成片
```

适合短剧、漫剧团队。若预算敏感，先做 30–60 秒样片并记录每个镜头的失败重试率，而不是直接生成整集。

### 方案 C：研发型全本地流水线

```text
InkOS / novel-studio（故事与长期状态）
  → novel2script / PenShot（结构化剧本、分镜 Prompt）
  → Wan2.2 TI2V-5B 或 MAGI-1 4.5B（本地镜头）
  → 本地 TTS
  → FFmpeg / Remotion（合成）
```

优点是可控、数据自持；缺点是集成成本最高，24GB 级 NVIDIA GPU 更现实。

### 方案 D：无 GPU 的批量解说视频

```text
主题
  → MoneyPrinterTurbo
  → LLM 文案 + Pexels/Pixabay 等素材 + 云/本地 TTS
  → 字幕、BGM、横竖屏成片
```

适合知识、营销、资讯和无真人出镜频道，不适合需要固定角色连续表演的剧情片。

## 9. 评估项目时建议实际验证的指标

1. **连续性**：20 章后人物年龄、关系、道具、时间线是否漂移。
2. **人工可控性**：能否只重做一章/一镜，而不是整批推倒重来。
3. **恢复能力**：API 超时、额度耗尽或进程退出后能否从 checkpoint 继续。
4. **角色一致性**：跨镜头脸型、服装、场景和关键道具是否稳定。
5. **单位成本**：每千字、每个可用镜头、每分钟成片的实际费用，而非单次 API 标价。
6. **失败重试率**：生成 20 个镜头后可直接使用的比例。
7. **后期可编辑性**：是否能导出分轨、字幕、剪映草稿、FCPXML/EDL，而不只是一个 MP4。
8. **许可证闭环**：代码、权重、输入素材、字体、音乐、语音和最终输出是否都满足发布场景。
9. **数据安全**：作品原文和角色资产是否发送给第三方 Provider，密钥是否加密保存。
10. **项目健康度**：最近推送、Release、Issue 响应、文档、迁移方案和测试覆盖，而不是只看 Stars。
